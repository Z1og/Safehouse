# Safehouse 0.1.14 · 控制台记住登录

## 登录保持

- 固定客户端设置与 Chromium 会话目录，沿用既有 Cookie 分区；更新或移动发布文件夹时不清理登录数据。
- 面板会话可能在服务器重启或到期后失效。新增登录页可选的「记住登录（仅本机加密保存）」：成功登录并确认有效会话后，使用 Windows 当前用户的系统加密保存账号信息。之后原 Cookie 无效时，客户端可以重新向原面板认证。
- 未勾选时不保存密码；有效 Cookie 直接沿用，不重复发送密码。普通登录和授权登录均支持，注册与 HTTP Basic 沿用原有方式。
- 保存信息按协议、域名和端口隔离，不能跨面板读取。无法使用系统加密时不回退明文；密码不写入设置、下载记录或日志。
- 主动退出面板或修改自己的密码会清除对应保存并取消正在执行的自动登录。增加工具栏「忘记登录」，可单独删除本机保存的账号信息。
- 服务端拒绝保存的账号后停止重试并清除记录；网络临时不可用时保留密文，避免连续尝试登录。

## 更新说明

退出旧客户端，完整解压 **Safehouse-0.1.14-win-x64.zip**，双击根目录 **Safehouse.exe**。

**此前丢失的登录无法凭空恢复。首次使用记住登录时，请勾选一次并手动登录。** 原有会话仍有效时无需重新登录；需要保存账号可在之后的登录页勾选。

永久数据继续使用 `%APPDATA%\Safehouse`，更新时保留该目录。主动退出登录后不会自动重新进入。

验证覆盖旧版到新版 Cookie 保留、不同 EXE 目录、真实系统加密、进程重启、服务端会话丢失、来源隔离、主动退出、忘记登录和密码失效。测试使用临时账号与游戏目录，不修改真实 Steam 订阅或模组。

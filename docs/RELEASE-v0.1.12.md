# Safehouse 0.1.12 · 工坊翻译修复

## 修复内容

- 翻译从仅依赖 Google 改为优先必应、Google 备用。Steam 工坊搜索和在线翻译是不同服务，工坊可访问不代表原翻译接口也可访问。
- 对整个翻译任务设置总等待时限，覆盖连接、响应正文和长描述的全部分段。服务不可用时保留原文并显示原因，详情提供「重试翻译」，不再长时间停在「正在翻译」。
- 标题翻译完成就更新对应卡片，不再等整页标题全部完成。详情的标题和说明分别显示成功结果；说明失败时仍保留已翻好的标题。
- 保留「查看原文 / 查看翻译」，关闭或切换详情后忽略旧请求结果。复用正在进行的相同翻译并缓存成功结果，暂不可用的服务会短暂退避，避免反复等待。
- 本机通过真实客户端网络实测，`Hiding Gnome [Vscript]` 及其公开英文说明可由必应翻译为中文。另有模拟断网、两服务失败、重试恢复、长文超时和界面回归测试。

## 更新方式

退出旧客户端，完整解压 **Safehouse-0.1.12-win-x64.zip**，双击根目录 **Safehouse.exe**。不要单独运行 `app` 子目录中的内部程序。

设置、面板会话、本地化记录和翻译缓存继续使用 `%APPDATA%\Safehouse`，更新时不要删除该目录。此版包含 0.1.11 的独立模组本地化、失败下载清理及此前的性能修复。

在线翻译只发送用户输入的搜索词及 Steam 社区公开标题、说明；不上传本地模组文件或账号凭据。网络服务仍可能临时不可用，失败时可保留原文继续浏览。

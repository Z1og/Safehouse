# Safehouse 0.1.15 · 安装版与客户端更新

- 新增 Windows x64 安装版 `Safehouse-Setup-0.1.15-x64.exe`，当前用户安装、可选目录、桌面 / 开始菜单快捷方式和系统卸载入口，无需管理员权限。
- 「偏好设置 → 应用更新」内直接检查 GitHub 正式版本，下载时展示真实进度，可取消或重试；安装包通过 SHA-512 校验后，主动点击重启安装。
- 安装前保存控制台会话，进行中的模组下载或安装会阻止升级；普通关闭不会自动安装，不在后台自动下载。
- 安装版与便携版继续共用固定用户数据目录，保留设置、收藏、面板 Cookie、已加密记住的登录与游戏模组。卸载应用也保留用户数据和游戏内容。
- 保留便携 ZIP；从 0.1.15 便携版可在客户端下载安装版。想继续使用便携版，也可在发布页下载新 ZIP。

## 首次升级

**0.1.14 及更早版本没有检查更新入口，请先手动下载安装本次 EXE。** 退出旧客户端后运行安装程序；不需要复制用户数据，不要删除 `%APPDATA%\Safehouse`。

后续在「偏好设置 → 应用更新」检查、下载并安装即可。更新来源为 GitHub Releases；网络不可用时支持重试或手动下载。发布程序暂未代码签名，Windows 可能提示未知发布者。

控制台记住登录仍需先勾选并成功登录一次；不会恢复从未保存过的密码，主动退出后也不会自动重新登录。

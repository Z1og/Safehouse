# 给求生之路 2 做了个「安全屋」，把 Mod 和服务器面板装进桌面

之前做了个 L4D2-Control，主要方便开服的人管理地图、插件和服务器。这次换个方向，给平时喜欢折腾 Mod 的玩家做了个 Windows 桌面客户端：**Safehouse · 安全屋**。

装完一堆地图、人物和枪械以后，我最常碰到的问题就是：这个包替换了谁？哪个是刚装的？要临时关掉一个，还得翻 addons。索性做了个界面，把本地模组、创意工坊和服务器控制台放到一起。

## 本地 Mod，终于能按角色和枪械找了

VPK 或 ZIP 直接拖进去就能导入，卡片里可以启用、禁用、看详情和删除。删除会先确认，再把游戏中的安装副本移到回收站，导入时的原文件会保留。

分类也不只写一个「幸存者」或「武器」：角色可以分到尼克、佐伊等八名幸存者，枪械可以继续分到 AK-47、M16、UZI、SPAS-12 这些具体替换槽位。想看有哪些包替换同一个角色，点对应标签就能集中查看，再逐项启停对照。

这里是帮你整理替换范围，不是宣称能自动查出所有冲突。已经装进本地的包优先看 VPK 里的实际资源，信息不足会如实显示。

## 逛工坊，也放进客户端

创意工坊支持关键词、项目 ID 或官方链接搜索，可以筛大类和更细的分类，卡片上也能看具体标签和详情。

本机 Steam 正常登录并运行后，就能在这里订阅、下载和安装；取消订阅时也会卸载对应的本地副本。管理器直接读取本机账号状态，不需要再填一遍 Steam 密码。

还加了中英文搜索：搜「初音」「尼克」「消音冲锋枪」这类词，也会尝试匹配对应英文。常用别名可以离线用，更多关键词依靠在线翻译；网络不通时保留原词，不会装作搜成功。

## 开服的朋友，也能接自己的控制台

有 L4D2-Control 的话，在「中心控制台」填自己的面板地址就能接入。地图、插件、玩家等服务器操作仍由原面板处理；Safehouse 负责把桌面入口、缩放、直连下载和本地安装串起来。

左侧还放了一个服务器连接卡片，从当前面板读取实际游戏地址和端口，点一下复制 `connect 地址:端口`。换服务器时跟着换，不把网页端口当成游戏端口。

不架服务器也能用，前面的本地模组管理和工坊功能不依赖面板。

## 怎么试用

目前是 Windows 10 / 11 x64 的 Beta 版。到 GitHub Releases 下载 ZIP，完整解压后双击 `Safehouse.exe`，玩家不用装 Node.js，也不用管理员权限。首次启动会自动找游戏，没找到就手动选目录。

**下载地址：** https://github.com/Z1og/Safehouse/releases/latest

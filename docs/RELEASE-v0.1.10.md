求生之路 2 的 Windows 桌面模组管理器，公开源码与首个 GitHub 发布版本。

## 已有功能

本地 VPK / ZIP 导入、启停、回收站删除；角色和武器槽位分类；中英文搜索；Steam 工坊订阅、下载与取消订阅卸载；中心控制台、面板直连下载和真实服务器连接命令复制。

## 使用方式

下载 **Safehouse-0.1.10-win-x64.zip**，完整解压，退出旧版本后双击 **Safehouse.exe**。支持 Windows 10 / 11 x64，不要求 Node.js 或管理员权限。请勿单独移动启动器。

设置和面板会话保存在 `%APPDATA%\Safehouse`，不要删除该目录。工坊功能需要本机 Steam 正常运行并拥有游戏。程序暂未签名，可能出现 Windows 发布者提示。

如需校验下载文件，对照随附 `.sha256` 文件。
